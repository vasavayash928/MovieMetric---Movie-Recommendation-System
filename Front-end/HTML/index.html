❓ Frequently Asked Questions
How does the AI recommendation work? +
MovieMetric uses TF-IDF Vectorization + Cosine Similarity. The recommendation is a hybrid score: 50% content similarity, 30% genre match, and 20% IMDb rating.
Which languages and movies are supported? +
We currently support Hindi (Bollywood), English (Hollywood), and Gujarati regional cinema with a database of over 900 films.
What is the Watch Party feature? +
Create a room to get a 6-digit uppercase code. Share it with friends so the AI can analyze everyone's preferences for a group consensus pick.
How does spoiler detection work? +
Our Python backend uses TextBlob for sentiment analysis and scans reviews against a multi-language list of spoiler keywords to automatically blur risky content.
Where can I watch these movies? +
Look for platform indicators on movie cards: N (Netflix), P (Amazon Prime), or H (Disney+ Hotstar).
Do I need to create an account? +
Browsing is public, but you need a JWT-secured account to save movies to your Watchlist or submit your own analyzed reviews.
